# Versions

*[Français](../fr/versions.md)*

The server saves a version of the project shortly after each change, with
the names of those who made it. The **Versions** tab of the left column
shows them, newest first, with the files that changed.

## Labelling

**Label this version** names a version, such as "Submitted". **Label the
project as it is now** does the same for the current state. Labelled
versions are kept for good; the others, the latest 1000.

## Comparing

**Compare** on a version, then checking another version, shows their
differences in the editor. **Stop comparing** goes back to the text.

## Restoring

- **Restore this file** brings a file back as it was in the version,
  including a file deleted since.
- **Restore** brings every file of the project back as it was in the
  version; files added since are kept.

A restore is a change too: it makes a new version, and nothing is lost.

## Downloading

**Download this version (.zip)** gives the files of the version, the text
without comments or tracked changes.

## And the Git history?

The **Git history** tab shows the commits of the repository linked to the
project; see [GitHub](github.md).
